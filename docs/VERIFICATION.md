## 公开包的离线回归

2026-10-11，最终 r2 包在 Windows/Python 3.14 下的 **21 组 focused 回归全部通过**。安装器的 31 项中，4 项实际符号链接测试因 Windows 权限跳过，其余 27 项通过；Linux CI 会执行这些检查。最终包的 401 刷新 14 项、解压/搜索与流协议集成 56 项也通过。

[GitHub Actions 的实际检查状态](https://github.com/wushuai0802/workbuddy2api-hub-ops-patch/actions/workflows/tests.yml)提供 Linux/Python 3.11 与 3.12 的最新结果。公开测试使用合成数据，真实推理样本原文不随包分发。

先准备**未安装补丁**的准确官方源码。在补丁仓库根目录运行：

~~~sh
python3 -B apply.py --verify-package
python3 -B scripts/test_offline.py --upstream /absolute/path/to/clean-official-v1.6.19 --output .work/verification
~~~

runner 核对基线，在隔离副本中应用补丁，然后运行安装器、本地保护和选定的上游 focused 回归。使用空账号/用量目录与合成夹具，测试子进程阻止非 loopback 网络；不调用付费模型、不使用真实凭据，也不运行上游全部 `tests/run_all.py`。

退出码和输出目录里的 `summary.json` 是该次运行的结果，各组日志也保存在对应目录。GitHub Actions 配置在 Python 3.11/3.12 上运行相同 runner；配置存在本身不等于 CI 已成功，应以实际 workflow 状态为准。

重新构建发布 ZIP 的入口：

~~~sh
python3 -B scripts/build_release.py --output /absolute/path/to/release-output
~~~

根目录 `MANIFEST.sha256` 覆盖公共源文件，`BASELINE.json` 固定目标基线；Release 的 `SHA256SUMS.txt` 用于核对 ZIP。发布输出是补丁和文档，不是账号数据或运行镜像。

## 隔离与部署检查

混合复读组件的此前候选容器在禁用网络、空账号、无公开端口的隔离环境中启动，健康与补丁 ID 检查通过。最终公开包还包含 401 刷新辅助方法和 deflate 依赖补全，不能将此前组件的运行结果当作最终包的线上验收；最终包应以离线回归、实际 CI 和使用者自己的部署检查为准。

本发布不提供带账号的容器或生产数据。公开回归应使用合成夹具与空数据目录；不要从自己的生产目录导入账号或完整历史来运行测试。

## 你的部署仍需验证

按 [INSTALL.md](INSTALL.md) 保留回滚后，核对运行版本与 `/health/retry` 的补丁 ID，检查控制台、账号、配置、历史、挂载和原鉴权策略。

恢复自己的正常流量时，观察实际使用协议、流式结束、工具结果与用量。若自行做模型测试，消耗和请求都属于你自己的部署；不应把离线 stub 的恢复结果当作线上成功率。

Issue 中可以提供脱敏的版本、协议、错误码、计数和最小合成样例。不要提交真实推理原文、会话数据库、账号/凭据、完整环境或包含它们的备份镜像。
