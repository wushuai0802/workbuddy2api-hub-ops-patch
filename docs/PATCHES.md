# 补丁范围与默认行为

版本 `v1.7.3-ops.20261014.1`，固定官方v1.7.3 / `c7dad8fe32316d47ce4f0ff260bb7ac7802b8a94`。修改四个上游模块、新增两个本地模块，不改变模型目录、账号数据格式或路由设置。

## 循环、期限与恢复

单次上游生成的高置信度推理/正文复读会明确失败。DeepSeek v4.1 Flash另用有界混合守卫识别极端行动句/Hmm密度；窗口最多128句、8192字符及2048字符行缓冲，保留代码、引用、实质证据等排除。

同一规则只扩展至解析器确认的前置thinking正文视图，普通正文不进入该视图。推理命中为`reasoning_loop_detected`；正文命中为`content_loop_detected`。

默认300秒共享生成期限。空答/纯推理循环共用最多一次恢复，正文、非空refusal、工具痕迹、超时或断开后禁止重放。精确上下文额外恢复熔断按显式会话与Key分域，不猜用户身份、不限制初始请求。通用跨工具回合业务进展熔断未实现。

## 历史、图片与协议

出站DeepSeek旧推理默认65536字符预算：相同别名只计一次，不同`reasoning_content`/`reasoning`分别计入，优先保留最新完整块，超额消息两字段一起置占位。只处理出站副本，保留原会话、正文、工具配对与结果；确认窗口内只清理完整重复Hmm句。

工具结果图片转成说明文本以兼容对应11133限制，用户图片保持。该转换会让此模型看不到该工具图片，不解决所有参数错误。

非空refusal保留为有效输出并禁止恢复；Messages保留其文本/终止原因及上游原生thinking，Responses保持独立内容索引和refusal delta/done。length/content_filter以incomplete状态/事件结束。n只支持整数1，其余请求上游前返回400；异常上游候选明确失败。

保留附件迁移中的完整DSML调用恢复、跨片大小写/全角标签和原生工具优先。缺少结束信号、存在流错误或未完整参数时不合成工具；完整可解析调用即使上游误标length仍遵循原生恢复规则。工具恢复不等于重新执行模型请求。

## 分块读取与连接所有权

保留官方64KiB读取块和阻塞读取前批量写出、共享TLS Context。首帧探测保留已读取前缀与剩余块，守卫和写出共享读取边界；避免包装器退回逐行读或越过前缀。

自然EOF可能早于缓冲帧的语义验证。因此只对守卫拥有的池响应延迟归池，验证完成后释放；循环/期限中止禁止复用。旧响应无法中止新租约。普通池API的自然EOF复用保持。已接收块中的用量在循环失败时保留，诊断不记录原文。

## 401、提示词与网页

401请求触发刷新共享原始绝对期限与30秒封顶，最多一次HTTP尝试，1MiB JSON上限。刷新连接独立不归池、不跟随重定向，取消并等待watchdog后清理；普通后台刷新保留原重试。系统DNS无法被强制中断，但迟到返回后不继续连接/发送过期凭据。账号代理出口和治理策略保持。

passthrough因403自动改写指令默认关闭；风控账号403仍保留官方冷却/换号路径。网页多引擎沿用官方实现，保留有界gzip/deflate解压、私网/重定向校验。显式自定义搜索后端默认不向其他引擎兜底，可用`WB_OPS_BING_FALLBACK=1`显式允许。

## 原生更新与迁移

v1.7.3保留命名空间自由格式工具回程、额外工具注入、面板640px默认限高/吸顶、响应头超时、国际版轻量活跃模型和最近请求尾读修复。此前1.7.0/1.7.2的单请求失败计账去重、风控403冷却/轮换、出口退避（默认关）、权重/备注、多引擎与缓存优化属于上游。

用量checkpoint升版可能重建，原JSONL应保持；公共入站上限仍16MiB，50MiB需显式配置。签到/连登管理按既有调度运行，补签/抽奖沿用官方消耗卡券/次数的行为。本包不更换模型、persona、effort、路由或账号。
