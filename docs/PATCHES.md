# 补丁范围与默认行为

本发布 `v1.6.20-ops.20261011.1` 以官方 v1.6.20 提交 `cb6a844588705ea01388be2b9df1f0cbbbcde357` 为基线。三个上游模块被修改，两个本地模块被新增；安装器不改变账号数据格式、模型目录、控制台或路由配置。v1.6.19 用户应使用[历史 r2 包](https://github.com/wushuai0802/workbuddy2api-hub-ops-patch/releases/tag/v1.6.19-ops.20261011.2)。

本次是针对新官方基线的迁移，保留下面的保护及 v1.6.20 的原生功能，不把旧补丁直接覆盖在新源码上。新增上游连接池 `wb_upstream_pool.py` 作为精确基线依赖核对，首帧与生成期限保护继续围绕新的上游读取路径工作；连接复用不增加工具重放权限。

## 1. 防循环与生成期限

在一次上游生成中检测高置信度的推理/正文重复，包括短句周期和极端重复意图。正文检测更保守。触发通过现有适配器返回明确失败，而不是伪装成正常完成。

默认共享生成期限为 300 秒，覆盖符合条件的恢复；连接/读空闲超时与这一总期限是不同约束。正常推理也可能耗尽 token 或时间，检测不能证明所有循环都被覆盖。

## 2. 混合复读保护

本地模块 `wb_stall.py` 仅在代理选中的 DeepSeek v4.1 Flash 推理中使用。它识别大量重复的行动短句与 Hmm 混在其他文字中的极端密度，防止只有完全连续重复才被发现。

窗口最多保留 128 句、8,192 字符和一个 2,048 字符行缓冲。检测使用短句类别、哈希和长度；代码、引用、数字证据与实质文字有保守保护。普通一句 “Let me go.” 或多轮工具结果不断变化不会因此被判定为故障。

命中继续使用 `reasoning_loop_detected` 和已有恢复安全门。**本发布没有实现按工具调用次数熔断的跨回合业务进展判断**，也不禁止所有同名工具轮询。

## 3. 最多一次安全恢复

符合条件的空回答与纯推理循环共用一次额外恢复额度和同一生成期限。已经输出正文、任何工具痕迹，或者超时/断开后，不自动重新执行请求，避免工具被重复执行。

额外恢复的相同上下文 circuit 需要显式会话标识和 API-key scope，只限制符合条件的额外恢复，不会根据猜测的身份阻断初始请求。检测失败和恢复失败都会保留错误与实际用量记账。

## 4. 出站推理历史保护

DeepSeek v4.1 Flash 的旧 assistant 推理默认总预算为 65,536 字符，优先保留较新的完整推理块；超预算的旧推理替换为协议需要的占位。该预算是字符数，不是输入 token 上限，也不压缩正文与工具结果。

之前已确认失败的推理前缀使用精确哈希做有限、进程内隔离；不会因为相似就删除成功历史。混合规则另清理已独立满足复读证据窗口中的完整重复 Hmm 句，并处理 `reasoning_content` 与 `reasoning` 两个别名。

处理只作用于发往上游的副本，不改客户端会话数据库。其余实质文本、行动句、可见正文、工具调用与工具结果保留。

## 5. 工具图片与 11133

DeepSeek v4.1 Flash 不能接受相应工具结果角色中的图片时，将 `tool` 内容里的 `image_url` 转为说明文本，避免此类 `11133` 错误。用户消息图片不受这个转换影响。

转换后的工具图片不会送给该模型看；需要模型理解图片内容时，使用受支持的用户图片路径。其他原因造成的 `11133` 不能由此保证解决。

## 6. HTTP 401 续期

上游返回 HTTP 401 后，在原账号凭据机制内进行受限刷新，再按安全条件重试。`wb_accounts.py` 提供所需的刷新辅助方法，避免代理的 401 处理调用缺失方法。刷新失败沿用原有错误/账号策略。它不更换你的 API Key、账号配置、代理槽或路由，不解决余额不足和全部账号不可用。

## 7. 回答与流协议

保留可信结束边界上的答案恢复、DSML 标签清理、首帧检查和显式截断错误。Chat、Responses 和 Messages 的流式/非流式适配器使用有保护的上游读取。

有界推理缓冲可以在交付前扣住短段推理。紧凑存储释放时还原原始帧，保持类型、JSON 拼写、字段顺序与 SSE 分隔。它有大小、条数、字符和到达驱动的时间上限，不缓存整个请求，也不能收回已交付的推理。缓冲释放计数不是失败请求数量。

观察到可疑短句的 `reasoning_stall_observed` 本身不代表错误；新混合规则满足更严格证据后才中断。

## 8. 提示词、网页与诊断

官方 passthrough 行为可能在 HTTP 403 后自动进入提示词降级并替换 system/developer 指令。本补丁默认关闭这一步，明确返回拒绝，避免影响后续请求的指令。显式配置的其他 prompt mode 仍保留自己的含义。

网页工具限制下载和解压大小，检查截断/不支持的压缩格式，完整导入 deflate 所需的 `zlib` 和搜索 RSS 解析所需的 `xml.etree.ElementTree` 标准库，并提供可配置的 Bing 搜索兜底。使用自定义 `WB_SEARCH_ENDPOINT` 时，兜底默认关闭；没有自定义搜索后端时，默认启用。兜底会将查询发送给另一搜索服务，可设 `WB_OPS_BING_FALLBACK=0` 关闭。

`/health/retry` 提供补丁 ID、恢复/循环/缓冲计数和有限近期事件，沿用原鉴权策略。新增循环诊断只记录数值、规则与有限形状信息，不记录推理原文；进程内循环计数会随重启重置。

## 常用开关

保留默认值通常即可。环境变量调整只影响对应行为，不为不兼容版本提供安装支持。

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `WB_OPS_LOOP_GUARD` | `1` | 单流与混合复读检测。 |
| `WB_OPS_GENERATION_TIMEOUT` | `300` | 共享生成期限秒数；`0` 关闭这一期限。 |
| `WB_OPS_LOOP_RETRY` | `1` | 循环恢复开关；空回答仍与其共享最多一次的额度。 |
| `WB_OPS_LOOP_CIRCUIT` | `1` | 显式会话/API-key scope 的相同上下文额外恢复保护。 |
| `WB_OPS_REASONING_BUFFER` | `1` | 有界推理缓冲。 |
| `WB_OPS_STALL_OBSERVE` | `1` | 短句观察与其有限额外缓冲。 |
| `WB_OPS_FAILED_REASONING_CLEANUP` | `1` | 精确失败前缀隔离。 |
| `WB_OPS_REASONING_RECOVERY` | `1` | 可信结束边界答案恢复。 |
| `WB_OPS_LEAKED_THINKING_GUARD` | `1` | 可见内容开头 thinking 标签的保守保护。 |
| `WB_OPS_MIXED_STALL_HISTORY` | `1` | 出站确认窗口中的重复 Hmm 清理。 |
| `WB_DEEPSEEK_REASONING_HISTORY_LIMIT` | `65536` | DeepSeek v4.1 Flash 旧推理字符预算。 |
| `WB_OPS_LOOP_RECOVERY_HINT` | `0` | 仅安全恢复时的实验提示；保持默认关闭。 |
| `WB_OPS_ALLOW_PROMPT_DEGRADE` | `0` | 显式允许官方 403 自动提示词降级。 |
| `WB_OPS_BING_FALLBACK` | 按后端 | 自定义搜索后端默认关闭，否则默认启用。 |

## 上游已有功能

账号签到/调度、缓存与账号亲和、账号配额与 HTTP 429 治理/切换、空 function 占位、工具历史配对和模型目录等由上游提供。本补丁在准确基线上保留它们，不能把这些原生功能全部归因于本地补丁。

v1.6.20 的面板回归修复、签到/活动记录、更新检查、剩余用量估算、持久化限额、连接复用、国内连登管家与登录限流修正也属于上游。面板会话失效后的 401 轮询修复不能代替模型请求的凭据续期；性能改进不能代替推理循环与生成期限保护。

公共补丁保留 v1.6.20 的 16 MiB 请求体默认上限和默认关闭的余量优先调度。国内自动补签/抽奖会用到对应卡券/次数；Docker/OpenWrt 服务端不提供客户端一键配置。按自己的需求显式调整，见 [INSTALL.md](INSTALL.md)。

本包不更换你的模型、不调整 persona/high effort/token 配置、不修改代理与协议路由。使用本包不意味着签到已经开启，也不意味着 429、模型拒绝或所有工具循环都能消失。
